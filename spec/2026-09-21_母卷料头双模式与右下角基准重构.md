# 2026-09-21 业务重构日志：母卷开卷排产与料头复用双模式分流及右下角基准重构

## 1. 变更背景与决策定调
根据业务实战需求，彻底解决“母卷直接开卷还是料头手工切混杂”的操作混乱问题，完成四大核心业务闭环重构：
1. **工位双模式物理级分流**：左侧控制台划分为清晰的“模式一：母卷开卷排产 (实扣母卷 ΔL)”与“模式二：料头复用精益切割 (母卷 0 消耗保证)”，消除操作混乱；
2. **母卷型号与料头库强绑定及切刀动态派生入库**：母卷与在库料头建立一对多关联。每次无论是母卷开卷下料还是料头二次套裁，未切尽部分自动登记入库归入该母卷旗下，库存数字即时联动；
3. **机台起准点全面校正为“右下角基准”**：依纺织机台靠右导轨对齐行业物理标准，原点统一标定在右下角 ($X$ 向左测幅宽，$Y$ 向上测进料长)，排料算例与光标坐标全面贴合右导轨；
4. **裁片需求卡片智能嗅探与决策选择**：每项待切裁片动态嗅探该母卷在库合用料头，醒目提供 `[⚡ 改用料头切 (0扣料)]` 与 `[🌀 坚持母卷切]` 选项，一键无缝切换模式与装载。
