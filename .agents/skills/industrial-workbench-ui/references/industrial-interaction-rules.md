# 工业现场防呆与数据可信度交互原则

在车间生产环境中，任何一个失误都可能导致物理材料报废、停线延误或工件损坏。
本指南列出现场人机交互的铁律与工程实现标准。

---

## 一、 输入保护与草稿容错 (Draft Protection)

1. **未失焦刷新保护**
   - 操作员在输入框键入数值后，即使尚未按 Tab 或回车（未触发 `change` 事件），按 F5 刷新或意外关闭页面，数据必须已通过 `input` 事件实时暂存至 `localStorage`。
2. **多任务草稿隔离**
   - 本地草稿按 `任务编号 + 外部工单号` 命名空间隔离，切换任务时自动保存当前上下文草稿。
3. **版本冲突与权威覆盖保护**
   - 当服务器端已有其他工位或调度员提交了新版本时，前端打开草稿必须提示：“服务器存在更新的版本”，禁止直接盲目覆盖，提供“保留本地草稿副本”与“拉取服务器事实”的显式选项。
4. **删除即时可撤销**
   - 误删需求行或疵点行时，不要弹出打断思路的阻断式 confirm 对话框，而是提供 5~10 秒的 Toast “已删除需求项 [撤销]”，点击可无损恢复。

---

## 二、 账实严密分离与透明度 (Truthful Accounting)

1. **预览不扣账，实切才记账**
   - **排料方案生成（Solve）**：仅代表几何算法的试排计算，状态记为 `PENDING`。
   - **报工提交（Report Confirm）**：现场工人完成真实物理切割后，核对实切长度并点击“报工保存”，此时才允许执行：
     - 扣减母卷剩余米数；
     - 将裁片计入需求完成件数；
     - 将勾选的余料料头生成唯一批号登记入库。
2. **区分“预计利用率”与“加工区占用率”**
   - **预计利用率** = $\frac{\sum 裁片净面积}{预计消耗原料面积}$；
   - **加工区占用率** = $\frac{\sum 裁片净面积}{整个机台台面面积}$；
   - 现场报表与卡片必须明确注明计算公式与分母，严禁将未利用的加工区空隙计入利用率，严禁将派生料头混入裁片净利用率。
3. **诚实解释未排入原因**
   - 方案未包含全部需求时，必须在结果区展开逐件说明：
     - “超宽超长”：裁片尺寸超过材料边界；
     - “旋转受限”：工艺禁止旋转导致排不下；
     - “疵点阻挡”：排料路径被标记的瑕疵阻隔；
     - “启发式时限截止”：在指定时限内未搜索到更优解（明确标注“不等于数学证明无解”）。

## 三、 手动调整方案闭环 (Manual Adjustment Loop)

1. **双重几何校验**
   - 前端 CAD 画布拖动裁片时实时进行轻量级干涉检测（包围盒重叠、越界变红）；
   - 放置后必须经过完整的多边形干涉与工艺切割线贯通性（Guillotine Cutability）硬性校验。
2. **撤销/重做栈 (Undo/Redo)**
   - 针对单次方案调整维护完整的状态快照栈，支持快捷键 `Ctrl+Z` 撤销、`Ctrl+Y` 重做。
3. **服务端权威保存**
   - 保存调整版时，前端将调整后的裁片绝对坐标发送给服务端验证，服务端重新生成标准刀路并赋予全新方案版本号（如 `V2-MANUAL`），原方案自动标记为作废但保留追溯记录。

## 四、 键盘与现场操作人体工程学 (Operator Ergonomics)

1. **工控机快捷微调**
   - 选中裁片后：
     - 方向键（`↑ ↓ ← →`）：步进 `5 mm` 微调；
     - `Shift` + 方向键：步进 `20 mm` 快速定位；
     - `R` 键：快速 90° 旋转（若工艺允许）；
     - `Esc` 键：取消当前选区或退出测量工具。
2. **全键盘模态窗操作**
   - 任何弹出窗必须保证：打开时焦点自动聚集在首个可输入字段，`Escape` 快速关闭，`Tab` 键循环在弹窗内部，绝不泄露到背景页面。
3. **触控防误触与无动画偏好**
   - 支持媒体查询 `@media (prefers-reduced-motion: reduce)`，在工控机或卡顿设备上自动关闭所有 CSS 过渡动画，保障现场秒级即时响应。
