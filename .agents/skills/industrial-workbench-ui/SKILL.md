# 工业现场工作台前端 UI 设计规范 (Industrial Workbench UI)

本规范提炼自工业级排产、裁切下料与现场制造工作台的最佳工程实践。
面向工业现场（工控机、车间触摸屏、现场操作员/排料员），核心价值是**“事实至上、防呆容错、单主动作、高密排布、清晰对账与工单闭环”**。

---

## 核心设计哲学 (Core Philosophy)

1. **事实第一与可信度原则 (Truth-First & Credibility)**
   - **严禁虚假计算与模糊修辞**：未求解就是未求解，计算中即显示明确进度/加载态，不可伪造完成度。
   - **严格分离“预览态”与“实绩态”**：
     - 排料预览**不扣减库存**、**不消耗需求剩余数**；
     - 报工确认才扣减原材料、计入合格成品、将实际余料登记入库。
   - **指标口径严密一致**：
     - **预计利用率** = 裁片净面积 ÷ 预计实际耗用原料面积；
     - **加工区占用率** = 裁片净面积 ÷ 机台加工台面总面积（展开明细中独立呈现，不可混淆）；
     - 料头回收面积单独记账，严禁混入成品利用率虚增指标。
   - **诚实呈现搜索结果**：未排入裁片必须解释原因（尺寸超限、旋转受限、疵点阻挡或搜索未排入），搜索未排入不得直接宣称为“数学证明无解”。

2. **现场防呆与误操作保护 (Foolproofing & Anti-Mistake)**
   - **草稿多重保护**：本地自动保留草稿，未失焦刷新可恢复，切换任务前二次确认，删除操作支持即时撤销。
   - **无副作用的流程导航**：点击顶部阶段步骤条（需求 → 材料 → 排料 → 报工）仅高亮并平滑定位对应区域，严禁触发任何后台隐式保存、重新求解或库存变更。
   - **破坏性操作强阻断**：切换其他材料规格或工位时，若存在未报工预览，必须弹出警告并要求用户明确勾选确认清理。
   - **手调闭环与权威校验**：支持手动拖拽裁片微调，但必须在前端与服务端经过硬性几何/工艺校验（越界、重叠、疵点干涉、贯通切割线完整性），未通过校验严禁进入报工。

3. **单一主动作心智 (Single Primary Action)**
   - 在任意作业阶段，右侧底部固定操作区永远**只突出 1 个最关键的主动作按钮**（如“完善需求” → “生成排料方案” → “报工保存”）。
   - 次要操作、辅助工具和撤销重做必须收拢或折叠，杜绝双主按钮造成车间工人心智负担。

4. **极端紧凑与画布优先 (Canvas First & Dense Layout)**
   - 适配两种典型工业桌面尺寸：**1366×768（车间一体机最低标准）** 与 **1920×1080（标准宽屏）**。
   - 关键材料摘要（编号、幅宽、余量）在左栏 **Sticky 吸顶**，即使需求清单滚动百行依然常驻可视。
   - 左右侧栏支持**自由拖拽调整宽度**及**一键边缘折叠（Edge Toggle）**，为中央 CAD 画布让出最大操作视野。

## 页面架构与三栏拓扑 (Page Layout Topology)

典型工业工作台页面划分为 5 大结构层：

```
+-----------------------------------------------------------------------------------+
| 1. Header (56px): [Mark + 系统名] [场景预设] [同级模块导航] [工单打印] [工具/设置] |
+-----------------------------------------------------------------------------------+
| 2. Task Bar (49px): [新建/打开/保存/草稿数]   [1需求 > 2材料 > 3排料 > 4报工]   [记录] |
+-----------------------------------------------------------------------------------+
| 3. Main Workspace (flex: 1; overflow: hidden;)                                    |
| +----------------+---+--------------------------------------+---+-----------------+ |
| | 左栏: 材料与需求 | R | 中栏: 工业 CAD 视口                    | R | 右栏: 结果与报工 | |
| | (320px, 可拖拽) | E | - 画布顶栏: 视图切换/图例指南          | E | (300px, 可拖拽) | |
| | - 材料摘要(吸顶) | S | - 全局材料/疵点雷达 (Radar Bar)       | S | - Tab: 结果/刀序 | |
| | - 需求完成度进度 | I | - CAD 标尺与工具条 (测距/图层/缩放)    | I | - 选中裁片微调   | |
| | - 紧凑需求表单   | Z | - Konva/Canvas 高性能绘图引擎         | Z | - 面积对账与台账 | |
| | - 工艺/疵点折叠卡| E | - 走刀仿真播放条 (可折叠)              | E | - 吸底主操作区   | |
| +----------------+---+--------------------------------------+---+-----------------+ |
+-----------------------------------------------------------------------------------+
| 4. Status Footer (24px): 当前材料批号 | 实时坐标(X, Y mm) | 缩放比 | 设备与引擎状态 |
+-----------------------------------------------------------------------------------+
```

## 视觉规范与 Design Tokens

所有样式统一使用 CSS 变量，确保暗色（车间大屏/低光环境）与浅色（办公室/高亮车间）平滑无缝切换。

### 1. 颜色体系 (Color Palette)

| Token 变量 | 暗色 (Dark) | 浅色 (Light) | 工业语义 |
| :--- | :--- | :--- | :--- |
| `--bg-dark` | `#0f172a` (Slate-900) | `#f8fafc` (Slate-50) | 全局底色 |
| `--panel-bg` | `#1e293b` (Slate-800) | `#ffffff` (White) | 面板背景色 |
| `--panel-header`| `#111e38` | `#f1f5f9` (Slate-100)| 卡片表头/表格Header/输入只读背景 |
| `--panel-border`| `#334155` (Slate-700) | `#cbd5e1` (Slate-300)| 边框线 |
| `--text-main` | `#f8fafc` | `#0f172a` | 主要文字 |
| `--text-muted` | `#94a3b8` | `#475569` | 辅助文字/单位/说明 |
| `--accent-blue` | `#0284c7` (Sky-600) | `#0284c7` (Sky-600) | 主控按钮、激活状态、选中焦点 |
| `--accent-green`| `#10b981` | `#059669` | 合格成品、需求达标、操作成功 |
| `--accent-red` | `#ef4444` | `#dc2626` | 瑕疵避让、裁片切割线、致命错误 |
| `--accent-amber`| `#f59e0b` | `#d97706` | 可用料头、待复核状态、操作警告 |

### 2. 控件规格 (Control Sizing)
- **圆角规范**：
  - 基础控件（按钮、输入框、下拉框、Tag）：`--control-radius: 4px;`
  - 弹窗与容器模态：`--dialog-radius: 8px;`
  - 状态微标（Badges）：`border-radius: 2px ~ 3px;`
- **尺寸基准**：
  - 标准输入控件高度：`34px`（内边距 `6px 8px`）；
  - 紧凑工具按钮高度：`30px`（内边距 `4px 10px`）；
  - 字体层级：主标题 `16px~18px`，正文/输入框 `12px~13px`，状态/微标/注释 `10px~11px`；
  - **数值与代码强制等宽字体**：`font-family: "JetBrains Mono", Consolas, monospace;`，确保工业尺寸与坐标对齐。

## 关键组件设计范式

### 1. 状态微标与明确文字 (Explicit Status Badges)
拒绝仅依赖颜色传达状态（色盲不友好、现场易误判），必须颜色与文本并存：
```html
<!-- 状态微标 -->
<span class="ui-status" data-state="PENDING">待报工</span>
<span class="ui-status" data-state="CONFIRMED">已确认</span>
<span class="ui-status" data-state="CANCELLED">已作废</span>

<!-- 工业类别微标 -->
<span class="badge-cut">2 刀</span>       <!-- 切刀/工序 -->
<span class="badge-piece">成品合格</span> <!-- 合格成品 -->
<span class="badge-rem">可用料头</span>   <!-- 派生余料 -->
```

### 2. 异常反馈与恢复机制卡片 (Operation Feedback)
统一带有左侧 3px 语义彩色边缘（绿色成功、琥珀色警告、红色错误），并**自带现场恢复入口**：
```html
<section class="operation-feedback" role="alert">
    <strong>排料失败：尺寸越界</strong>
    <p>需求 3 (1200×2500) 超过当前材料幅宽 2000mm 且禁止旋转。</p>
    <div class="feedback-actions">
        <button class="tool-btn" onclick="locateInvalidInput()">定位输入字段</button>
        <button class="tool-btn" onclick="retrySolve()">重新排料</button>
    </div>
</section>
```

### 3. 原生模态弹窗规范 (`<dialog>`)
全站弹窗统一采用原生 HTML5 `<dialog>` 搭配 `::backdrop`，居中对齐，支持 `Escape` 关闭，禁用模糊滤镜：
```html
<dialog id="custom-modal" class="workflow-dialog">
    <div class="workflow-dialog-heading">
        <h2>弹窗标题</h2>
        <button class="tool-btn" onclick="this.closest('dialog').close()">关闭</button>
    </div>
    <div class="workflow-dialog-body">
        <!-- 滚动内容区 -->
    </div>
    <div class="workflow-dialog-footer">
        <button class="tool-btn" onclick="this.closest('dialog').close()">取消</button>
        <button class="tool-btn active" onclick="submitModal()">确认执行</button>
    </div>
</dialog>
```

### 4. 现场工单打印规范 (A4 Cut Ticket)
工单不仅是屏幕弹窗，更是随材料流转的纸质凭证：
- **页面设置**：`@page { size: A4 portrait; margin: 12mm; }`
- **打印介质净化**：`@media print` 下隐藏所有工作台控件，仅保留纯白背景工单。
- **防止截断**：`header, .ticket-meta, .ticket-diagram, tr { break-inside: avoid; }`
- **必备五要素**：
  1. 稳定且可扫码的工单号（等宽字体）；
  2. 任务、材料批号、规格与时间元数据；
  3. 等比例矢线下刀图解（含加工区标注与下刀顺序）；
  4. 裁片明细表（长、宽、需求编号、合格件、异常件登记）；
  5. 现场操作员、质检员与领料人签字栏。

## 落地实施规范检查清单 (Checklist)

开发或评审工业工作台界面时，核对以下 10 点：

- [ ] **1. 单位透明度**：所有输入框与指标展示均带有显式物理单位（`mm`, `m`, `m²`, `件`）。
- [ ] **2. 精度保留**：长度与位置支持至少 `0.1mm` 浮点数，不得粗暴整数取整破坏工业对齐。
- [ ] **3. 状态双保险**：每个状态显示均包含“文本标签”与“语义色彩”，不单独使用红绿圆点。
- [ ] **4. 双尺寸兼容**：在 `1366×768` 视口下验证，主报工按钮与材料摘要无需二次滚动始终常驻可视。
- [ ] **5. 操作单主导**：右侧吸底区永远仅保留 1 个大主按钮，次级动作收拢进折叠菜单。
- [ ] **6. 阶段纯定位**：点击步骤条仅滚动页面展开区域，无网络请求、无持久化、无计算副作用。
- [ ] **7. 账实严格分离**：未报工的排料图仅标为“预览方案”，报工后方可在列表标记“已完成”。
- [ ] **8. 双向画布联动**：点击需求行可快速在 CAD 画布上高亮对应裁片；点击画布裁片能反查需求行。
- [ ] **9. 键盘可操作性**：支持 `Escape` 关闭弹窗、方向键微调裁片、`R` 键快速旋转 90°。
- [ ] **10. 打印防截断**：工单打印在 A4 打印机或 PDF 预览下，无任何界面按钮残留，表格跨页表头自动重复。
