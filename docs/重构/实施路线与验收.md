## 第一批实现及调用链

`/app/#/workbench/{taskId}/{planId?}` → 宿主读取任务、方案、报工、材料、执行单/失效检查 → `model/roll-scene.js` 将工位局部坐标加卷长偏移 → `js/canvas/roll-canvas.js` 创建独立 Konva 舞台 → 回调选择、移动或疵点建议 → 宿主原有预检与保存流程。

- 场景保留材料/裁片/料头的真实 `shape`；结果中已旋转轮廓直接绘制。拖动只发世界坐标增量；凹多边形空白处不能命中。矩形旋转后的宽高同步到显示轮廓。
- 复用既有 `nesting-renderer.shapeNode` 与场景几何，`roll-camera.js` 承担连续母卷/工位相机。原 `app/js/canvas/` 导入路径保留转发，不更改宿主调用契约。
- 每实例拥有舞台、图层、相机、工具、选择、Pointer Capture、AbortController、ResizeObserver 和 RAF。提供 `setScene/getView/setView/setTool/setSelection/setVisible/destroy`，同时保留宿主使用的相机/比例接口。销毁幂等，隐藏不接受手势，不请求 API 或修改库存。
- 保留横竖、整条/平铺、毫米坐标、精确比例、测量、标疵、母卷导航与手调。窄屏工作台可横向滚动，避免固定侧栏把画布压成零宽；桌面双栏布局不变。
- 半透明平面裁片关闭逐对象整屏缓冲绘制；不省略轮廓/节点来换取性能。性能结果必须按同机交替测量门槛验收。
