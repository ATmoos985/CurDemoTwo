- **双轨并发竞态校准与稳定性复跑加固（M3 Iteration 4）**：
  - **勘误说明**：Iteration 3 日志原述“HTTP 10/10 轮严格返回 1 个 `200` + 1 个 `409`”忽略了跨 HTTP 线程的 `AuthSecurityFilter` 前置鉴权竞态——当胜方先提交事务禁用败方并递增 `token_version` 后，后进入 Filter 的败方请求会即时返回 `401 UNAUTHORIZED`（而非进入 Controller 返回 `409`），独立复跑第 4 轮实测为 `s1=401, s2=200`。
  - **方案 A（HTTP 全链并发无竞态断言 + 动态胜方复位）**：在 `SecurityAndAuditIntegrationTests.percentEncodedPathsNewRollConservationAndConcurrentAdminDisableAreHardened` 中改为 10 轮 `CyclicBarrier(2)`（`10s` 等待超时、`15s` Future 超时）校验每轮严格 `1 个 200 + 1 个 ∈ {401, 409}`（禁止双 `200` 与 `500`/`503`）、`countActiveAdmins() == 1L`、胜方启用与败方禁用状态一致、败方旧 Token 立即访问 `/api/v2/users` 返回 `401`，并由实际 `200` 胜方重登复位恢复 `countActiveAdmins() == 2L`。
  - **方案 B（Service/DB 事务层确定性 `1×SUCCESS + 1×IllegalStateException` 压测）**：注入 `@Autowired SecurityAdminService`，以 10 轮 `CyclicBarrier(2)` 直接并发调用 `updateUserStatus` 压测 `JdbcSecurityCredentialStore` 行锁互斥，实证 10/10 轮严格 `1×SUCCESS + 1×CONFLICT_LAST_ADMIN`（仅匹配 `"不能禁用最后一个活跃管理员账号"`，不吞 `DataAccessException` 等异常）、`countActiveAdmins() == 1L`、零死锁；第 10 轮进一步校验唯一活跃管理员通过 HTTP 禁用自身确定性返回 `409`；保留 `finally` 复位 `admin=true, admin2=false` 保持同类用例零顺序依赖。
  - **连续 5 次独立 Maven 进程复跑**：连续 5 次独立执行 `.\mvnw.cmd test "-Dtest=SecurityAndAuditIntegrationTests"`（每轮新建独立随机 Schema 与 Spring Context，规避单 Context `600/min` 写限流干扰），5/5 轮全部 `Tests run: 3, Failures: 0, Errors: 0, Skipped: 0`（单轮测试耗时 10.88–16.00 s，总累计 50 轮 HTTP 并发 + 50 轮 DB 并发 0 flaky）。
