## 核心改动与实测效果
1. **NFP 对称性反演 + 跨会话有界 LRU 缓存**：基于归一化顶点签名与中心反演 `scale(-1, -1)` 复用 `OuterNFP(B, A)`；线程安全有界 LRU（上限 2048），写入前 `getBounds2D()` 预热并读取防御性拷贝，消除 `Area` 多线程竞态并支持跨 `STRIP_SEARCH` 复用。
2. **热路径 AABB 粗筛**：`DeepnestSolverEngine`、`DeepnestNfpGeometry.mergedLength`、`JavaIrregularSolverEngine`、`ContourGeometrySupport.violatesMinEdgeGap` 与 `PolygonResultValidator` 统一先经 AABB 粗筛再做精确几何检测，消除无效 `Area` 重建。
3. **压紧器解锁间距与疵点**：`MarkerCompactor` 与 `AxisMarkerCompactor` 对裁片-裁片碰撞采用 `pieceGap / 2 + 0.002mm` 欧氏外扩构造 `SlabProfile`（避免斜边轴向距离失真），`AxisMarkerCompactor` 将安全外扩后的疵点作为位移锁死为 0 的固定障碍纳入最长路约束图，出口统一经 `PolygonResultValidator` 零容忍验真与安全回退。
4. **确定性有界并行评估**：`NestingParallelExecutor`（上限 `Math.min(4, availableProcessors)`，调用线程执行第 0 任务，按原索引确定性归约，取消时立即 `cancel(true)` 并保留中断标志）接入 `DeepnestSolverEngine` 与 `JavaIrregularSolverEngine`。
5. **基准实测提速**（`DeepnestSolverEngineTests`）：
   - L-Shape 4-Rot (8pcs)：`deepnest` 158ms → 65ms (-59%)，`javairregular` 112ms → 67ms (-40%)
   - U-Frame Pocket (8pcs)：`deepnest` 66ms → 34ms (-48%)，`javairregular` 15ms → 9ms (-40%)
   - Shirt M+L 5mm Gap (18pcs)：`deepnest` 408ms → 188ms (-54%)，`javairregular` 269ms → 122ms (-55%)
   - Shirt M+L 180-Deg (18pcs)：`deepnest` 393ms → 129ms (-67%)，`javairregular` 382ms → 124ms (-68%)
