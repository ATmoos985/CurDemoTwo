# 2026-11-17 UI 信息架构与工作流收敛重构（`reaction` 分支）

## 一、核心决策与重构目标

　　针对原界面“生产闭环、单点试算工具与演示沙盒混排在一处”、“任务跳转丢失操作意图”、“工作台顶栏层数过多且右栏堆砌全生命周期按钮”以及“库存单据裸打 JSON 与重复流水”四项问题，基于现有代码在 `reaction` 分支完成收敛重构：

1. **导航成熟度分层（生产 vs. 试算 vs. 演示沙盒）**：将左侧常驻导航重构为顶部三大核心业务域（`生产闭环`、`工艺试算`、`材料与台账`）与底部独立停靠区（`沙盒与配置`：能力展示、设置），并在顶部栏右侧提供“演示沙盒”与“系统设置”快捷入口；将辅助视图（执行与报工、复检处置、库存单据、生产分析）收敛为带缩进的二级导航项（`.nav-sub`），同时在页面标题栏内提供同域视图切换胶囊（`.hub-tabs`）。
2. **任务动作意图直达（Intent Direct Routing）**：打通 `#/workbench/:taskId/:planId?intent=report|quality|adjust` 路由参数；从任务队列、工位执行单、异常复检列表点击“去报工”或“打开处置/处理异常”进入工作台时，自动定位对应工位并直接展开报工抽屉或复检处置抽屉，消除二次寻找按钮的操作损耗。
3. **排料工作台（`workbench.js`）顶栏降高与右栏按阶段收拢**：
   - 将原 3 层顶栏合并为紧凑双层结构（高度由约 140px 降至约 82px），并将静态阶段条（`1需求 > 2材料 > 3排料 > 4执行 > 5报工`）改造为无后台写副作用的交互式定位按钮（点击直接展开需求/材料浮层或切换右栏阶段视图）。
   - 在右栏指标卡下方新增四档视图过滤栏（`全部` / `微调与工具` / `执行与缺口` / `记录`）；将原分散的方案工具与导出按钮整合为紧凑 `.tool-grid`，将空闲执行单收拢为单行 `.exec-inline`，将无缺口时的“本次未排入”空状态框压缩为单行绿色状态条 `.sec-inline`，并精简冗余的规则说明文字。
4. **服装唛架幅宽试算（`garment.js`）升级与生产衔接**：在右栏顶部新增 4 格实时成本与效率 KPI 摘要（最低单件克重、推荐最优门幅、最高利用率、本版配码/齐套进度），并在排料图工具栏新增“导出唛架 JSON”与“转入生产任务 ↗”按钮，支持将已验证的齐套唛架一键转为新建二维生产任务草稿。
5. **沙盒分类与单据结构化渲染（`showcase.js`、`documents.js`）**：在能力展示页增加按算法类别与业务演练沙盒切换的分段筛选栏；在库存单据页将移库单与盘点单原本裸打的 `JSON.stringify` 替换为结构化工业表格。

## 三、真实 AAMA/ASTM DXF 服装纸样接入与齐套搭切（`1226.dxf` / `20148D.dxf` / `3129.dxf`）

　　将三份真实服装 CAD 纸样（`1226.dxf` 卫衣大货版、`20148D.dxf` 二套版 T 恤、`3129.dxf` 连帽开衫与长裤套装）完整提取并接入系统的服装工艺试算、算法演示沙盒与生产排料工作台：

1. **真实轮廓提取、丝缕线对齐与左右对称镜像配片（`dxf-garment-samples.js`）**：解析 GB18030 编码的 AAMA/ASTM DXF `BLOCK` 实体、Layer 1 裁切外框 `POLYLINE` 与 Layer 7 丝缕线（经向一致）；将各款 `110`–`160` 共 6 个尺码的 32 种裁片外框归零并保拓扑简化至 ≤36 个顶点（面积误差 <0.12%），对标注 `Quantity: 1,1`（`L:1-R:1`）的成对裁片自动生成左片与 X 轴镜像右片，实现真实左右对称互补密排。
2. **全链路集成与 `.dxf` 纸样直导（`marker-demo.js`、`garment.js`、`showcase.js`、`task-edit.js`）**：
   - 在服装工艺试算（`#/garment`）与唛架样式（`MARKER_STYLES`）首位预置 `DXF_1226`、`DXF_20148D`、`DXF_3129` 三款真实 DXF 纸样及多门幅试算案例；
   - 在演示沙盒（`#/showcase`）与业务流程模板（`WORKFLOW_TEMPLATES`）新增三款 DXF 齐套唛架与业务演练模板；
   - 在新建/编辑任务页（`#/task/new`）新增“一键载入 DXF 1226 / 20148D / 3129”快捷按钮，并支持直接上传解析 `.dxf` 纸样文件；在排料工作台（`#/workbench`）缺料提示处支持一键登记并检验匹配门幅的母卷。
3. **实算验证结果（`packingsolver-irregular`）**：
   - `1226.dxf`（120+140 码面布 8 片）：1650 mm 门幅下实算唛架长 `970.7 mm`–`988.5 mm`，齐套利用率达 `79.99%`（单件用料 `228.31 g/件`）；
   - `20148D.dxf`（120+140 码面布 8 片）：1500 mm 门幅下 7 轮缩短试排实算唛架长 `1010.0 mm`，齐套单床全部排入（0 缺口）；
   - `3129.dxf`（120 码连帽开衫+长裤全套面布 22 片）：1750 mm 门幅下实算拉布长 `1237.2 mm`，齐套利用率达 `72.73%`。
