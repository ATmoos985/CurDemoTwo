# 修复全站数字输入框编辑时强制回弹无法正常输入问题（2026-11-24）

## 1. 根因分析
- **现象**：在智能搭切工作台修改「门幅 W」等数字输入框时，按退格删减、全选清空或逐字输入新数值（如将 `1650` 改为 `1400`）会被瞬间弹回下限（`300`）或默认值（`1500`），无法正常键入数字。
- **直接原因**：全站 13 个页面/弹窗中共 129 处受控 `<input type="number">` 在 `onChange` 中直接执行了 `Math.max(min, Number(e.target.value) || fallback)` 或 `Number(e.target.value)`，导致：
  1. 严重回弹（63 处）：输入过程处于空白或暂小于 `min`（如输入 `1400` 途中的 `""`、`1`、`14`、`140`）时，立即被钳位或回退并写回受控 `value`。
  2. 清空变 0（66 处）：清空时 `Number("") === 0`，立即被写回 `"0"`，导致前导零黏连或小数中间态被打断。

## 2. 修复方案
- 新增通用受控数字输入组件 `frontend/src/components/ui/NumberInput.tsx`（保留原生 `type="number"` 与 `forwardRef`，兼容既有 CSS 与浏览器测试选择器）：
  - 内部维护字符串草稿状态，聚焦编辑期间允许空值、退格、小数中间态及暂未达下限的输入，绝不打断键入。
  - 仅当输入为完整合法数字且落在 `[min, max]` 区间内时实时触发 `onValueChange`，保证联动指标与快捷按钮实时生效。
  - 失焦（`onBlur`）或按 `Enter` 时统一做空值回落（`fallback`）与 `[min, max]` 钳位；若最终值与外部值相同，不误触发变更回调。
  - 外部状态更新（如点击常用门幅快捷按钮、切换母卷/模板）时自动同步显示值。
- 将全站 13 个页面/组件中的 129 处受控数字输入框统一替换为 `NumberInput`：
  - `frontend/src/pages/CuttingWorkbenchPage.tsx`（34 处）
  - `frontend/src/pages/DemandCreatePage.tsx`（16 处）
  - `frontend/src/pages/ShowcasePage.tsx`（14 处）
  - `frontend/src/pages/TaskEditPage.tsx`（13 处）
  - `frontend/src/components/SettingsModal.tsx`（11 处）
  - `frontend/src/pages/NestingStudio2DPage.tsx`（9 处）
  - `frontend/src/pages/SlittingStudio1DPage.tsx`（9 处）
  - `frontend/src/pages/DemandPoolPage.tsx`（8 处）
  - `frontend/src/pages/ClusterCenterPage.tsx`（6 处）
  - `frontend/src/pages/ExecutionCenterPage.tsx`（4 处）
  - `frontend/src/pages/InspectionPage.tsx`（2 处）
  - `frontend/src/pages/GarmentWidthPage.tsx`（2 处）
  - `frontend/src/pages/ResultsCenterPage.tsx`（1 处）
