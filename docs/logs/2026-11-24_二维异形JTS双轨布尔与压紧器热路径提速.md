# 2026-11-24 二维异形 JTS 快慢双轨布尔与压紧器热路径提速

## 变更目标
在保持 Phase 4B/4C 高利用率与零容忍几何校验的前提下，针对 JTS 布尔热路径、增量可行域长尾及带 `pieceGap > 0` 压紧器热路径进行定向提速优化。

## 核心改动与实测效果
1. **JTS 快慢双轨分流**：`DeepnestNfpGeometry` 布尔差/并/交增加外接框剪枝、不相交 $O(1)$ 直拼 `MultiPolygon`、子分量预筛与轻量 `OverlayNG.overlay` 快轨，仅 `TopologyException` 时回退 `OverlayNGRobust` + `GeometryFixer`；所有缓存几何预热 envelope 保证多线程只读安全。
2. **增量可行域与双重 Bound-and-Prune**：`DeepnestSolverEngine` 增量 `clipCache` 与 LNS `keptFeasibleCache` 升级为剩余可行域 `feasibleNfp` 逐个差集递推 + 无交集跳过，引入局部 Y 视窗裁剪及 `maxAllowedExtentY` / 跨角度 `upperBoundScore` 数学剪枝。
3. **压紧器近线性双指针扫描**：`MarkerCompactor.firstFreeY` 将 $O(|A| \times |B|)$ slab 嵌套扫描优化为 $O(|A| + |B|)$ 双指针扫描，以原始 `double[]` 原地排序去重替换 `TreeSet<Double>` 装箱。
4. **实测提速对比**（版长与条带利用率 100% 持平零回退）：
   - Case5 (Shirt M+L 0°, 5mm Gap, 18pcs)：`2264ms → 740ms`（**-67.3%，3.06×**）
   - B3 (Valance + L Mix, 12pcs, 4mm Gap)：`1566ms → 366ms`（**-76.6%，4.28×**）
   - B4 (Shirt M+L 0°, 5mm Gap, 18pcs)：`2198ms → 584ms`（**-73.4%，3.76×**）
   - Case1 (L-Shape 4-Rot, 8pcs)：`534ms → 300ms`（**-43.8%**）
   - `Phase4bHybridPipelineTests` 总耗时：`12.29s → 3.376s`（**-72.5%，3.64×**）
