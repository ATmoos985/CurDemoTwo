# 2026-11-24 工作台求解过程极简 UI 与流式交互升级

## 决策背景
工作台在 1D 一维分切与 2D 二维排料求解全链路中存在大量解释性文字、括号说明、重复状态提示以及超长 toast 弹窗（如 `后台并行求解中，完成后自动上屏`、`较逐规格独立分切减少 X 车 上机排刀`、`正在计算并独立校验结果`、`选定此方案（扣减需求并保存结果）` 等），且 2D 多策略求解需等待全部算法完成后才统一上屏。本次按极简工业 UI/UX 风格重构，用直观的状态视觉、骨架占位、实时计时与流式上屏替代文字说教。

## 变更文件清单
- `frontend/src/pages/workbench/workbenchTypes.ts`：精简 2D 策略名称（`经向缩长` / `旋转缩长` / `异形进化` / `异形经向` / `快速基线`）及求解目标短标签（`齐套最短` / `齐套补空` / `定长装满` / `多幅比选`），说明移入 `title` 悬停提示。
- `frontend/src/store/studioSettings.ts`：同步精简设置弹窗中的 2D 策略展示名与副标，保证全站命名统一。
- `frontend/src/store/useStudioStore.ts`：为 `addSchemes2D` 增加 `selectIfBetter` / `batchIds` 流式增量合并选项，避免后到低分方案抢占已显示的更优方案；补充 `StrategyJobRun.errorDetail` 与 `SlittingSchemeRun.errorMessage`。
- `frontend/src/pages/workbench/useWorkbenchSolver.ts`：
  - 新增 `solveElapsedMs` 真实求解秒表计时器；
  - 2D 并发求解升级为**流式逐个上屏**（每完成一个策略立即渲染到底部候选条与画布）；
  - 不再透传后端冗长 `j.message`，状态行改用纯数据指标与极短异常标签；
  - 1D 策略名精简为 `快捷解` / `精确解` / `独立分切`，移除求解成功态超长 toast，仅保留关键异常、中止与落库确认反馈。
- `frontend/src/pages/CuttingWorkbenchPage.tsx`：向中央与右侧面板透传 `solveElapsedMs` 与 `baselineCars1D`。
- `frontend/src/pages/workbench/WorkbenchCenterPanel.tsx`：
  - 移除 1D 顶部冗长 `.roi-banner` 横幅，改为在方案卡片主数字旁直接内嵌省车绿标（`−122车`）与 `最优` 微标；
  - 1D 运行中卡片改用顶部流光进度线 + 脉冲点实时计时 + 工业轻量骨架占位，彻底移除重复的“计算中…”与“后台并行求解中，完成后自动上屏”；
  - 耗时 ≥ 1000ms 自动格式化为秒（如 `16.1s`）；缺口/超产为 0 时不再凑字展示。
- `frontend/src/pages/workbench/WorkbenchRightPanel.tsx`：
  - 2D 实时求解区改用 2px 进度轨道 + 语义状态点 + 实时秒表/纯指标；
  - 求解目标由带说明书的单选列表收拢为 2×2 紧凑按钮网格（2D）与 1×2 分段开关（1D），完整解释放入 `title`；
  - 精简主操作文案：`选定此方案`、`查看结果`、`保存中…`、`计算中…`。
- `frontend/src/pages/workbench/SlittingConfigCard.tsx`：精简卡片标题、档位/模式按钮与折叠参数头（隐藏 `NewSolver` 内部术语并同步展示真实 `slitMaxDistinctWidths`），移除预设切换冗余 toast。
- `frontend/src/pages/workbench/WorkbenchDemandSidebar.tsx`：移除切换需求族/载入模板时的冗余 toast。
- `frontend/src/pages/ShowcasePage.tsx`：统一算法实验室求解状态文案为极简词（`排队中` / `计算中` / `齐套` / `未齐套` / `已停止`）。
- `frontend/src/styles/theme-workbench-v2.css`：新增状态脉冲点、2px 进度条、紧凑目标网格、1D 卡片省车微标与轻量骨架样式（含 `prefers-reduced-motion` 兼容）。
- `src/test/browser/app-unified-workflow.cjs`：同步更新端到端验收脚本中的 `选定此方案` 与 `查看结果` 选择器。
