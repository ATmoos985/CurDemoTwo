# 2026-11-24 重构工作台右侧一维参数面板 UI 与消除重复配置

## 决策背景
工作台右侧一维参数区存在 6 处直观 UI/UX 缺陷：
1. 顶栏 `一维参数` 折叠弹窗与右栏重复配置母卷幅宽、切边、组合宽与超产上限，职责混乱；
2. 右栏 `.seg` 分段控件缺失 `flex: 1`，按钮左缩、右半边漏出死灰背景；
3. `快捷 / 精确` 与 `☑ 双档对比` 并存导致逻辑冲突（勾选双档时单选仍高亮但实际不生效）；
4. 切换到「固定宽」时，跨 2 列输入框下方仅剩单个 `求解时限` 导致右半边留出空洞；
5. 标签携带 `(mm)` / `(卷)` / `(秒)` 括号，且无分组卡片边界，与上方 KPI 卡混成一团；
6. 同一窄栏内出现 3 个跳转/展开高级参数的入口。

## 变更文件清单
- `frontend/src/pages/workbench/SlittingConfigCard.tsx`：
  - 收拢为浅灰圆角分组卡 `分切工艺`，头部直接显示动态 `净宽` 徽标，移除与顶栏重复的 `母卷总宽` 输入框与右上角重复 `高级 ↗` 按钮；
  - 所有数字输入框改用内嵌单位（`mm` / `卷` / `秒` / `ms`）；
  - 对称排布：`左切边 | 右切边` → `[ 可变组合宽 | 固定组合宽 ]` → 固定宽单行 `组合宽` / 可变宽 3 等分 `最小宽 | 最大宽 | 步长` → `超产上限 | 求解时限` → 折叠 `更多参数`，彻底消除半行空洞。
- `frontend/src/pages/workbench/WorkbenchRightPanel.tsx`：
  - 将一维求解档位与目标合并为独立的 `求解策略` 分组卡，档位改为无冲突的三段式切换 `[ 快捷 | 精确 | 双档 ]`，下方紧邻 `[ 最少车数 | 最高利用 ]`；
  - 二维 `求解目标` 同步收拢进同款 `.wb-param-card` 分组盒，保持 1D/2D 视觉语言一致。
- `frontend/src/pages/workbench/WorkbenchTopBar.tsx` & `frontend/src/pages/CuttingWorkbenchPage.tsx`：
  - 移除顶栏中与右栏完全重复的 `一维参数` 折叠弹窗，使顶栏专注「母卷来源 + 幅宽 + 定长」，与 2D 顶栏完全对称。
- `frontend/src/styles/theme-workbench-v2.css`：
  - 统一 `.studio-right .seg button { flex: 1; justify-content: center; }` 修复右栏全部等宽分段开关；
  - 新增 `.wb-param-card`、`.wb-param-grid-2`、`.wb-param-grid-3`、`.wb-field-inline`、`.wb-input-unit`、`.wb-param-fold` 工业级紧凑属性栏样式。
- `src/main/resources/static/app/dist/{react-app.js,main.css}`：生产构建产物更新。
