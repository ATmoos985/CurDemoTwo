## 核心改动要点
1. **`IsolatedProcessRunner`**：统一封装子进程执行、50ms 步进轮询 `ComputationCancellation.check()`、进程树强杀与临时目录递归清理；补齐原生直刀/异形引擎的协作取消响应；`ModuleBoundaryTests` 保持 `business`/`controller` 白名单不变，仅增量放行 `algorithm.runtime` 给 `nesting`/`slitting`。
2. **`CoordinateFrame` 与 `GuillotinePostProcessor`**：统一 `startCorner` 双向镜像、回零点、`trimStart` 第 0 刀、连续母卷尾段判定、疵点打标及刀路补齐/优化串联。
3. **`StripSearchCapable` SPI**：消除 `SolverFactory` 对具体异形引擎类的 `instanceof` 硬编码。
4. **`ContourGeometrySupport`**：留在 `algorithm.nesting` 包内（不扩大 `algorithm.geometry` 对外暴露面），收拢异形疵点外扩、AABB 粗筛与碰撞/最小边段间距检测。
