# 2026-11-28 · 工作台侧栏本位收折与全站平滑缩放动效升级

## 1. 背景与目标

1. 原搭切工作台右上角 `[◀ 需求] [方案 ▶]` 开关使用无语义字符且高亮状态与实际展开状态反转，用户无法直观理解其作用，视觉也较生硬。
2. 全站 6 个共用 `WorkbenchBoardCanvas` / `CadCanvasView` 的画布页面（搭切工作台、验布打标、卷料台账实物预览、方案与工单、示例沙盒、服装唛架）在滚轮缩放、按钮缩放、居中适配与焦点追踪时均无过渡动效；全站 4 处侧栏收折均以直接卸载或硬切 `grid-template-columns` 实现，体感僵硬且丢失滚动位置。

## 2. 本次核心改动

### 2.1 搭切工作台右上角与左右侧栏本位收折重设计
- **极简线性图标组件**（`frontend/src/components/ui/LayoutIcons.tsx`）：提供 `CollapseLeftIcon`、`ExpandLeftIcon`、`CollapseRightIcon`、`ExpandRightIcon`、`FocusCanvasIcon`、`ZoomMinusIcon`、`ZoomPlusIcon`。
- **空间本位收折 + 画布边缘召回 + 单一专注按钮**：
  - `WorkbenchTopBar.tsx`：移除原 `[◀ 需求] [方案 ▶]` 双按钮，改为单一「专注画布 / 恢复面板」按钮（`Alt+\`），直观一键收起左右双栏并记住专注前的单边状态；
  - `WorkbenchDemandSidebar.tsx` / `WorkbenchRightPanel.tsx`：各自在 `.pane-h` 右侧就近提供线性图标收起按钮（`Alt+[`、`Alt+]`）；
  - `WorkbenchCenterPanel.tsx`：当对应侧栏收起时，在 2D 画布或 1D 条带左右边缘呈现毛玻璃召回微胶囊；
  - `WorkbenchWorkspaceView.tsx`：保持左右栏挂载不卸载 DOM，切换时保留内部滚动位置与展开态。

### 2.2 全站 Figma 级画布相机平滑缩放动效
- **纯数学相机动效模块**（`frontend/src/components/canvas/canvasCameraMotion.ts`）：实现 `easeOutExpo`、连续对数滚轮灵敏度归一化 `computeWheelZoomFactor`、锚点锁定 `computeZoomCameraAroundPoint`、透视倒数直线推拉补间 `computeStraightZoomTweenState`、帧率无关指数阻尼步进 `stepExponentialZoomDamp` 及 `prefersReducedMotion()` 无障碍兜底。
- **全站相机控制器与交互胶囊**（`canvasCamera.ts`、`canvasStageMount.ts`、`WorkbenchBoardCanvas.tsx`）：
  - 鼠标滚轮/触控板缩放改由 `zoomWheel` 连续阻尼驱动，光标锚点零漂移；
  - 按钮缩放、居中适配 `fitView`、重置卷位 `resetRollOffset`、疵点/区间聚焦 `focusRange` 默认执行 200~260ms `easeOutExpo` 对数平滑补间；首次加载自适应保持 `immediate: true` 零闪飞；
  - 验布自动跑布 `followPosition` 启用平滑追赶；指针拖拽与双指捏合按下时 `cancelAnimation()` 即时打断；
  - 画布右下角 `.wb-board-zoom-pill` 升级为交互式悬浮缩放胶囊（`[−] [100%] [+]`, 点击百分比平滑适配全览）。

### 2.3 全站 4 处侧栏平滑收缩曲线统一
- 在 `theme-magpie.css` 定义 `--cp-ease-out-expo: cubic-bezier(0.22, 1, 0.36, 1)`、`--cp-dur-panel: 260ms` 及 `prefers-reduced-motion: reduce` 归零规则；
- 统一升级：全局左侧主导航栏（`App.tsx` + `theme-magpie.css`，含边缘把手箭头旋转）、搭切工作台左右栏（`theme-workbench-v2.css`）、验布打标右侧疵点记录栏（`InspectionCanvasWorkspace.tsx` + `theme-magpie-inventory.css`，保留 `#toggle-panel`）、卷料台账右侧实物预览窗格（`InventoryPage.tsx` + `InventoryPreviewPane.tsx` + `theme-magpie-inventory.css`，拖拽调宽 `.is-resizing` 时关闭过渡保证零延迟跟手）。
