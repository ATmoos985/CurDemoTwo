# 2026-11-24 一维分切条带改用蓝灰单色阶与联动高亮

## 决策背景
此前 `SlittingStripBar` 使用 `STRIP_COLORS[w % 7]` 对 7 种高饱和度彩虹色取模配色，导致不同规格频繁撞色（如 790 与 1000、850 与 1130），且橙/红/绿易被误解为告警或达标状态。用户选定方案 A：全部正常条带改用统一工业冷蓝单色阶（按宽度由窄到宽柔和渐变），配合左侧订单与右侧条带的双向联动高亮。

## 变更文件清单
- `frontend/src/pages/workbench/SlittingStripBar.tsx`：移除 `STRIP_COLORS[w % 7]`，新增 `stripToneByWidth` 按全局宽幅范围映射冷蓝单色阶（窄条通透浅蓝 → 宽条沉稳冷蓝，文字对比度 ≥ WCAG AA），支持 `highlightedWidthMm`、`dimAll`、`onHoverWidth` 交互。
- `frontend/src/pages/workbench/workbenchTypes.ts`：删除已无引用的随机彩虹色数组 `STRIP_COLORS`。
- `frontend/src/pages/workbench/WorkbenchCenterPanel.tsx`：
  - 计算当前方案全局 `[minWidthMm, maxWidthMm]` 传入所有刀组，保证跨组同宽同色；
  - 接入左侧 `activeHighlightKey`（精准按 `allocations` 命中当前订单并展示 `本单 N 卷` 微标，无分配数据时退化为按宽度匹配）及右侧条带悬停同宽聚焦；
  - 在「刀组排布」标题栏集成 3 点极简图例（`窄→宽` / `切边` / `余宽`）。
- `frontend/src/pages/ResultsCenterPage.tsx`：同步计算并传入全方案全局宽度上下限，保持结果页与工作台视觉口径一致。
- `frontend/src/styles/studio.css`：优化刀口分隔线、聚焦高亮态（主靛蓝 `#5b61f6` + 白字）、非命中淡化态、石板灰切边、45° 余宽斜纹与极简图例样式。
- `src/main/resources/static/app/dist/{react-app.js,main.css}`：生产构建产物更新。
