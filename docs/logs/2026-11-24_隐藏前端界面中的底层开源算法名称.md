# 2026-11-24 隐藏前端界面中的底层开源算法名称

## 决策背景
用户明确要求界面中不提及 `OR-Tools`、`Deepnest` 等底层算法/求解器名称，需对外保持统一简洁的业务品牌表达。同时排查发现系统设置页引擎列表原样渲染了内部引擎 ID（如 `deepnest`、`ortools-1d`、`packingsolver`、`javaguillotine`），以及若干配置面板和旧历史方案标题残留 `NewSolver`、`PackingSolver`、`Java`、`C++`、`NFP`、`MIP`、`LNS` 等底层术语。

## 变更文件清单
- `frontend/src/components/SettingsModal.tsx`：
  - 新增 `ENGINE_DISPLAY_NAMES` 与 `ENGINE_MODE_LABELS` 展示映射，引擎表格隐藏 `deepnest` / `ortools-1d` / `packingsolver` / `javaguillotine` 等内部 ID，改为面向业务的引擎名称与中文工艺标签；
  - 将 `一维分切求解器参数（NewSolver / OR-Tools）`、`缺原生内核时回退 Java`、`NewSolver 惩罚权重与 B 层搜索微调`、`MIP 单阶段安全时限`、`精确解启用 LNS 大邻域搜索` 等全部改为简洁业务名称，同时修正已过时的自动扩宽至 5 规格说明。
- `frontend/src/pages/workbench/WorkbenchCenterPanel.tsx`：移除卡片 `title` 中残留的 `OR-Tools 快捷解 (FAST)` / `OR-Tools 精确解 (QUALITY)`。
- `frontend/src/pages/workbench/WorkbenchTopBar.tsx`：`打开 NewSolver 高级参数设置…` → `高级求解参数设置…`。
- `frontend/src/pages/workbench/SlittingConfigCard.tsx`：`MIP 单阶段安全时限 (ms)` → `单阶段时限 (ms)`。
- `frontend/src/pages/workbench/workbenchTypes.ts` & `frontend/src/store/studioSettings.ts`：隐藏 2D 策略徽章和短标签中的 `C++`、`NFP`、`GA` 等底层实现词，统一为业务维度标签（`经向` / `旋转` / `异形` / `极速`）。
- `frontend/src/pages/ShowcasePage.tsx`：移除 `NewSolver`、`MIP`、`LNS`、`Polygon NFP`、`Column Generation` 等技术词。
- `frontend/src/pages/ResultsCenterPage.tsx`：新增 `sanitizeSchemeTitle` 展示清洗函数，确保历史已落库方案标题中旧的 `OR-Tools`、`Deepnest`、`PackingSolver`、`NewSolver` 字样也不再对外展示。
- `src/main/java/changyang/cut/apsmodule/service/OptimizationResultAssembler.java`：接口返回 `algorithmType` 由 `"OR-Tools 列生成"` 改为 `"列生成分切优化"`。
- `src/main/resources/static/app/dist/{react-app.js,main.css}`：生产构建产物更新。
