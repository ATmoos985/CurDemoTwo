# 跨环节加工正确性、复检一致性与生产闭环全面清零（2026-11-25）

## 1. 背景与目标

本轮工作围绕生产现场最易触发真实损失的四类跨环节缺陷展开收口与端到端闭环验证：
1. **带孔裁片全链路无损与 CNC 加工正确性**：从需求池落盘、2D 排料请求适配、方案确认/物化到 CNC G-Code 与 AutoCAD R12 DXF 导出，保证内孔 `shape.holes` 全链路无损，并严格按“先切全部内孔、后切外轮廓”生成刀路，新增 DXF `1_PIECES_HOLES` 独立图层；
2. **工位边界 20mm 安全边距避疵裁窗一致性**：统一前端排料/画布与后端联排的裁窗语义（先外扩安全边距再按工位窗裁剪），根治位于工位起切线外沿但 20mm 安全禁区侵入本工位的边界疵点丢失问题；
3. **跨任务合排复检净良品归属、采购适配过滤、一维刀架物理硬约束与 Outbox 崩溃自愈**：精确核算多任务合排下复检判废对各任务净良品面积与残值的归属，剔除门幅/缸号/色号不可适配备料库存，前端完整接入 1D 刀架物理硬约束与工作台实绩/复检同步视图，并实现 Outbox Worker 崩溃重启双保险自愈（本地原子状态文件 + 后端 `rejectedToken` 列表兜底）；
4. **面向当前 React 主路由的现代真机验收与四层 Konva 性能基线**：补齐 `app-react-closure-and-perf.cjs` 现代真机脚本并清零进度文档历史断链与基准测试口径偏差。
