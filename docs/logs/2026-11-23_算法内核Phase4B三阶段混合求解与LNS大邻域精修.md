## 核心改动与基准效果
1. **三阶段预算调度**：留出出口安全裕量，划分为阶段 1（构造 + 并行 GA）、阶段 2（LNS 大邻域精修，件数 `>= 4` 且未达理论下界时触发）、阶段 3（`polishPlacements` + `MarkerCompactor` & `AxisMarkerCompactor` 联动压紧 + `PolygonResultValidator` 零容忍兜底）。
2. **确定性 LNS（`Ruin-and-Recreate`）**：固定派生种子，轮换 3 种 Ruin 策略（高 Y 末端 / 空间邻域 / 确定性随机子集，拔出 15%–30% 且同步纳回未放件）与 4 种 Recreate 启发序，复用 `keptNfpCache` 避免重复并集，完整遵守 Phase 3 `ConstraintPipeline` 与 `ComputationCancellation`。
3. **候选点截断优化**：常规 28 / 件数 `>= 12` 为 36 / LNS 为 48，截断后分层补检至多 6 个低 Y / 边界贴合代表点。
4. **基准实测提升**：
   - Case6（Shirt M+L 180°, 18 pcs）：版长 `1555.0 → 1539.6 mm`（缩短 15.4 mm），条带利用率 `78.37% → 79.16%`；
   - Case7（Skirt+Jeans 180°, 14 pcs）：版长 `1805.0 → 1803.7 mm`，条带利用率 `81.18% → 81.23%`；
   - Case2 理论最优早停保持 `12 ms`。
