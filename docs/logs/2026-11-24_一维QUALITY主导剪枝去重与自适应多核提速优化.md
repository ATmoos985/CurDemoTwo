## 核心改动与实测提速
1. **B 层最优 `(over, rolls)` 主导预剪枝**：`CuttingSolver.pruneDominatedCandidates` 严格对齐 `DeterministicPlanSelector` 前两级字典序，跳过注定落选的高车数候选的 Stage5+LNS 计算。
2. **A 层 `p0` 安全去重**：仅在 Stage1–3 全部 SCIP `OPTIMAL` 且需求键顺序一致时复用 Stage3 进 Stage4，`fast-baseline` 始终保底候选池首位。
3. **自适应受控并发与全链路 native 释放**：`cutdemo.slitting.child-threads=auto` 在 2 核云端容器保持 1 线程保 OOM，4+ 核机器受控 2–3 线程；消除嵌套抢占全局槽位自锁；补齐 Stage1–5 / Repack / LNS 的 `finally { solver.delete(); }`。
4. **LNS 缓存与无改进早停**：跳过无收益邻域并收口早停，1T 与 3T 结果 100% 确定一致。
5. **实测对比（`overCap=0, 60s`）**：
   - `T10-17` QUALITY：`15.79s → 6.24s`（**2.53×**），150 车 / 95.00%
   - `T29-50` QUALITY：`50.16s (参考 56.8s) → 8.37s`（**6.0×**），697 车 / 95.06%
