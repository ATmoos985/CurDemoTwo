# 2026-11-18 迁移 Deepnest 二维异形切割算法与对比实测记录

## 1. 迁移背景与目标

　　围绕 `D:\GitHub\Deepnest` 核心二维异形排样源码（`minkowski.cc`、`main/background.js`、`main/deepnest.js`、`main/util/geometryutil.js`），将其核心临界多边形（No-Fit Polygon, NFP）卷积几何层、增量布尔裁剪缓存、共边合并奖励与遗传算法（Genetic Algorithm）进化搜索完整抽取并迁移至本项目的纯 Java 二维算法模块 `com.example.cutdemotwo.algorithm.nesting`，注册为独立可插拔引擎 `deepnest`，接入后端轮廓工作流与前端二维排样工作台并行对照策略，并通过 7 组典型异形与服装真实样板与现有 `javairregular`（天际线锚点挤压启发式）及原生 C++ `packingsolver-irregular` 进行同输入实测对比。
