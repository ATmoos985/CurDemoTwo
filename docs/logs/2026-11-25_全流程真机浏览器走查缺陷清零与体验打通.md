# 2026-11-25 全流程真机浏览器走查缺陷清零与体验打通

## 1. 背景与走查方式

在前四阶段演进完成后，为验证全站从「采购入库 → 跑布验疵放行 → 车间领料 → 需求建单与排程 → 结果中心复盘/条码工单/完工 → 对账与复检补片 → 联合排产/自动分床 → 成本与备料分析 → 企业认证 5 角色 RBAC + SSE」的真实工厂可用性，基于隔离端口与独立系统临时目录（免登 `18085`、企业认证 `18086`，不污染正式 `data/` 库存），通过内置浏览器开展了两轮真机全流程端到端走查、集中根因修复与全量真机复测。
