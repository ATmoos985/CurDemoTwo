# 2026-11-19 修复全引擎求解时限抢杀与边界校验问题

## 问题根因

1. **求解引擎内部时限与作业硬截止竞态（主因）**：`OptimizationService.execute()` 在到达 `timeLimitSeconds` 整点时通过定时任务向工作线程发送 `thread.interrupt()`；而原生直刀引擎（`PackingSolverService`）与原生异形引擎（`IrregularPackingSolverService`）直接向 C++ 可执行文件透传整数 `--time-limit N` 并开启 `--only-write-at-the-end`，加上进程启动、输入解析与结果写出耗时（约 `0.4–1.2s`），导致任何未提前证优的算例都在 C++ 写出 `certificate` 之前被强杀，抛出 `InterruptedException` 并返回无结果的 `TIMED_OUT`（“计算已退出，达到时限”）。全量扫描 27 个演示算例时，`4 (多规格套裁)`、`6 (连续送料工位)`、`GARMENT_SHIRT`、`GARMENT_PANTS`、`GARMENT_FULL` 共 5 处均因此稳定失败。同类无余量时限问题同时存在于 `DeepnestSolverEngine`、`JavaIrregularSolverEngine`、`LinearSlittingSolverEngine` 与 `MarkerOptimization`。
2. **前端求解参数越界风险**：`CuttingWorkbenchPage`、`SettingsModal` 与 `studioSettings` 允许将 `timeLimitSeconds` 配置或缩放至最高 `120s`，超出后端校验上限 `60s`（`NestingValidation` / `SlittingValidation`）；`CuttingWorkbenchPage`、`NestingStudio2DPage` 与 `IrregularPackingSolverService` 对含安全裕量（`margin` / `clearance`）的疵点禁入区未裁剪到母卷边界 `[0, width] × [0, height]`，靠近卷边时易触发校验拒收。

## 变更文件

- `src/main/java/com/example/cutdemotwo/algorithm/nesting/PackingSolverService.java`：向原生直刀求解器传入带安全余量的浮点秒数 `--time-limit`（`nativeTimeLimitSeconds`，如 `3s -> 2.25s`、`10s -> 8.20s`），确保在作业截止前正常落盘 `certificate.csv` 并退出。
- `src/main/java/com/example/cutdemotwo/algorithm/nesting/IrregularPackingSolverService.java`：传入带余量的浮点秒数 `--time-limit`（如 `3s -> 2.15s`、`10s -> 7.80s`），并在 `nativeInput()` 中将外扩安全边距裁剪至材料矩形边界内。
- `src/main/java/com/example/cutdemotwo/algorithm/nesting/DeepnestSolverEngine.java`：为 GA 搜索与坐标打磨阶段预留收尾余量，避免在输出组装阶段被整点中断丢弃已得可行解。
- `src/main/java/com/example/cutdemotwo/algorithm/nesting/JavaIrregularSolverEngine.java`：为多轮排样预留收尾余量，避免在组装最终结果时因整点中断丢弃已有 `bestPlan`。
- `src/main/java/com/example/cutdemotwo/algorithm/slitting/LinearSlittingSolverEngine.java`：扣除子 JVM 启动与序列化开销后再下发 OR-Tools 内部预算 `internalBudgetMs`。
- `src/main/java/com/example/cutdemotwo/business/optimization/MarkerOptimization.java`：为外层唛架缩长与空隙补片编排预留收尾余量。
- `frontend/src/store/studioSettings.ts`、`frontend/src/components/SettingsModal.tsx`、`frontend/src/pages/CuttingWorkbenchPage.tsx`、`frontend/src/pages/NestingStudio2DPage.tsx`：统一将 `timeLimitSeconds` 上限对齐后端 `1–60s`，并将含外扩安全边距的疵点禁入区严格裁剪到材料边界内。
