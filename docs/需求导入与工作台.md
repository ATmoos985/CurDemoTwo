# 需求导入与工作台

“新建任务”直接打开任务编辑窗口，上方填写名称与材料型号，在需求清单旁导入文件、使用 9.28 样例或手动添加需求。关联订单号默认收起。新任务不默认选中库存的第一个型号，手动添加也不预填演示尺寸；导入会自动填写型号。需求齐备后点击“保存并选择材料”，保存成功即进入母卷与料头选择。中途关闭可稍后继续，切换任务沿用草稿保护。

导入支持 `.xlsx`、UTF-8 `.csv` 和现有切割任务 `.json`，先按文件中的布料编号与型号分组，再勾选该组的需求行放入当前任务；保留任务名称，不再暗中另建任务。文件在浏览器本地解析，保存需求时才写入服务器。名称、型号、需求尺寸和件数未填写完整，或超过 200 项时，编辑器提示原因并禁用保存；其他保存入口同样先检查，避免把空需求送到服务器后再显示笼统报错。已保存任务通过需求窗口编辑；导入另一批需求须新建任务，避免覆盖已报工的需求身份。

9.28.xlsx 原表共 104 行订单、162 片：27 种明确布料，另有 2 行布料待定。内置样例与上传文件共用相同解析规则，可导入 26 种布料的 100 项、156 片。第 78、79 行（布料 894512）未确认裁切方向，第 108、109 行布料待定，保留原表行号和原因但不能勾选。左侧不会因库存缺卷而隐藏文件布料；切换布料会清空上一组勾选。

## 9.28 订单格式

支持原表中的换行表头和多行表头。RH 横裁沿用项目现有口径：

- 裁片幅宽方向 = 裁布高度（R 列）× 10。
- 裁片卷长方向 = 单片每片宽度（N 列）或双片每片宽度（P 列）× 10。
- 需求数量 = 订单支数（J 列）× 单 / 双片系数（1 / 2）。
- 按布料编号（D 列）＋供应商编号（E 列，作为材料型号）分组，保持订单编号、布料编号和来源行可追溯。
- 不自动旋转，不按最大拼接片数自动拆片。非横裁、缺尺寸或型号等异常行列出原因，异常行不可勾选，只导入明确选中的有效需求。

Excel 导入不创建母卷、库存、疵点或完成量。与库存按完整型号精确匹配，有匹配母卷时会在提交前重新核对并实际装载该卷；无匹配母卷时可先导入需求。JSON 中旧任务的 ID、版本、完成量和材料来源也不会恢复。

## 订单演示库存

启用现有 `cutdemo.seed-demo-data` 时，启动会补齐 9.28 表中 27 种明确布料的演示母卷，并为这些卷及原有 4 种演示卷各预置 3 块料头：整片、带疵、窄条。已有母卷的尺寸、余长、库存状态和报工事实不覆盖；已消耗或报废的预置料头不会重生。共享数据库默认不启用演示种子。

新演示卷统一 100 m，幅宽至少 2800 mm，按原表所需裁布高度向上取整到 100 mm；料头尺寸按该布料需求范围预置，均标注“演示预置（非实物）”。这些物理参数不是 Excel 提供的实物库存数据。原表未提供裁切方向的 894512 也有演示母卷和料头，但需求仍须补齐方向后才能导入。

## 标准格式

导入窗口可下载 UTF-8 CSV 模板。列名：`订单编号,材料型号,裁片名称,宽度(mm),长度(mm),数量,允许旋转`。允许旋转填“是”或“否”，空白按否处理；尺寸大于零，数量为正整数。

JSON 使用现有任务的需求字段：

```json
{"name":"批次需求","materialModel":"面料型号","externalRef":"订单号","demands":[{"name":"裁片 A","width":600,"length":800,"quantity":2,"allowRotation":false}]}
```

每次选择一种材料建立任务。文件最大 10 MB，工作表最多 10000 行，超限明确拒绝，不截断导入。

## 布局与操作

- 左栏为输入：当前任务、需求摘要、用料、料头匹配、机台参数和排料。右栏为输出：排入数量、用料与面积、刀序、最近报工与新增料头。需求只显示简表，详细编辑通过弹窗完成。
- 点击顶部“需求”或单项需求打开当前任务的需求弹窗；点击“材料”打开“当前用料与疵点 / 母卷库存 / 料头库存”。顶部库存入口也在本页打开弹窗。
- 当前用料显示疵点分布及坐标、尺寸、避让余量。原有编辑入口放在详情下方。样例母卷编号有来源提示。
- 画布工具栏“库存档案”右侧的“料头”打开双页签窗口：“本次预计新增”与“当前母卷料头库”。第二页内可按当前剩余需求、工艺和疵点计算推荐。推荐可核对每项可切数量；只有确认装载才切换当前材料。
- 推荐仍沿用现有范围：最多 8 块尺寸候选、每块搜索 1 秒。推荐不是报工，也不代表全局最优。
- “库存档案”的料头库显示全部可用库存；画布“料头”窗口只显示当前母卷的料头；“试排推荐”只针对当前任务的剩余需求。无候选时区分无同型号库存、尺寸 / 工艺不符和需求已完成。
- 报工后刷新库存和剩余需求；存在匹配料头时自动试排并显示首选料头。右侧最近报工保留本次新增料头编号、型号及尺寸，未匹配也能查看入库事实。自动试排不自动装载、不保存新方案。
- 空白新任务不自动装载母卷；从 Excel 导入时装载所选的关联母卷。默认允许纵横套裁、不旋转；工艺参数仍可调整。整卷重置收在材料弹窗的“重置搭切记录”。
- “裁切试验”集中提供整幅横切、二维避疵、短料头复用、多规格套裁、连续送料加工区、异形排料六类演示；不保存业务任务或扣库存。连续送料示例只展示单个加工区，完整多工位报工仍在裁切作业中进行。
