# 需求导入与工作台

顶部“导入需求”支持 `.xlsx`、UTF-8 `.csv` 和现有切割任务 `.json`。文件在浏览器本地解析，按材料型号选择一组需求建立新草稿；原任务沿用已有的草稿保护流程。保存需求时才写入服务器。

## 9.28 订单格式

支持原表中的换行表头和多行表头。RH 横裁沿用项目现有口径：

- 裁片幅宽方向 = 裁布高度（R 列）× 10。
- 裁片卷长方向 = 单片每片宽度（N 列）或双片每片宽度（P 列）× 10。
- 需求数量 = 订单支数（J 列）× 单 / 双片系数（1 / 2）。
- 按供应商编号（E 列）作为材料型号分组，保持订单编号、布料编号和来源行可追溯。
- 不自动旋转，不按最大拼接片数自动拆片。非横裁、缺尺寸或型号等异常行列出原因，明确勾选跳过后才能导入有效行。

原表不提供的母卷长度、库存、疵点、报工完成量不会生成。JSON 中旧任务的 ID、版本、完成量和材料来源也不会恢复。

## 标准格式

导入窗口可下载 UTF-8 CSV 模板。列名：`订单编号,材料型号,裁片名称,宽度(mm),长度(mm),数量,允许旋转`。允许旋转填“是”或“否”，空白按否处理；尺寸大于零，数量为正整数。

JSON 使用现有任务的需求字段：

```json
{"name":"批次需求","materialModel":"面料型号","externalRef":"订单号","demands":[{"name":"裁片 A","width":600,"length":800,"quantity":2,"allowRotation":false}]}
```

每次选择一种材料建立任务。文件最大 10 MB，工作表最多 10000 行，超限明确拒绝，不截断导入。

## 布局与操作

- 左栏显示各需求的合格完成量和剩余量；点击“管理需求”或单项需求打开同一份编辑弹窗。
- “详情”显示当前母卷 / 料头的疵点分布及坐标、尺寸、避让余量。原有编辑入口放在详情下方。样例母卷编号有来源提示。
- “料头推荐”常驻左栏，打开时按当前剩余需求、工艺和疵点自动试排。推荐可核对每项可切数量；只有确认装载才切换当前材料。
- 推荐仍沿用现有范围：最多 8 块尺寸候选、每块搜索 1 秒。推荐不是报工，也不代表全局最优。
- 新任务不自动装载母卷。演示案例及整卷重置收进顶部“演示”。

## 验证

`node --test src/test/js/*.test.mjs` 包含需求导入的方向、单位、双片数量、无效行、分组、JSON 字段隔离以及 XLSX / CSV 读取验证。

浏览器需检查：导入预览 / 取消 / 旧草稿保留、需求编辑及定位、母卷疵点、料头自动推荐及关闭不切料，以及 1366×768 / 1920×1080 布局。文件选择若受浏览器扩展权限限制，可手动选择本机文件验证，不需要扩大应用权限。
