### 1.2 迁移边界与保留事项

- `src/main/resources/static/` 顶层已严格收敛为 `app/`（Vite 产物）与 `api-v2/`（OpenAPI 3.1 / JSON Schema 契约）；全部历史经典 `.html`/`.css`/`static/js` 与 5 个旧 React 兼容页已彻底清退，旧 Hash 路由自动重定向至对应现代页面。
- 共享几何 DTO 中保留部分兼容展示/质检字段以兼容存量数据；不意味着所有字段都属于最终 v2 算法契约。
- 算法中的 Spring 注册与原生进程适配暂时保留；当前受 `ModuleBoundaryTests` 严格约束，禁止依赖业务对象和存储。
- 旧一维页面宿主 `linear/` 已彻底移除；标准 `SLITTING_1D` 通过 `algorithm/slitting/` 隔离进程适配复用 `changyang` 纯算法内核，`ModuleBoundaryTests` 已移除白名单并禁止全仓其他任何包引用 `changyang.*`。
- 标准业务和 HTTP 调用不得直接依赖 `algorithm/nesting`、`algorithm/slitting` 或 `algorithm/toolpath` 实现；通过 `algorithm/api` 注入，纯几何函数可复用 `algorithm/geometry`。
- 前端画布已重构为组件级四层独立 Konva Layer（`WorkbenchBoardCanvas` / `CadCanvasView`），`frontend/src/lib/canvas/` 保持零业务/零传输边界。
- 业务服务同时支持 File 与 MySQL JDBC（Flyway V1–V10）存储端口，含不可变账本流水、企业轻量认证（默认关闭按需开启）、Outbox 投递与复检处置受控撤销。
