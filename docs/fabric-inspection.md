# 跑布验疵

入口：顶部「跑布验疵」，独立页面 `/inspection.html`。

1. 选择已有母卷，或「新建母卷」登记卷号、型号、幅宽和整卷长度。
2. 把现场累计读数填到「当前位置」，点「定位 / 校准」。单位为米，支持 0.1 mm 精度。
3. 手动模式按「前进一段」移动指定长度；自动模式设置 `m/min` 后开始滚动，可随时暂停和校准。位置由速度与经过时间计算，不读取设备里程。离开页面或浏览其他区域会暂停自动滚动。
4. 横向验布线上的刻度表示距右边缘的毫米数，线右侧显示当前累计米数。左侧纵向刻度表示距卷头的米数。
5. 在布面按住左键拖出疵点范围，松开记录；反向拖动也可以。可以连续标记，不弹出确认框。选择工具支持移动疵点、拖四角调整大小；右侧表单可精确修改。
6. 疵点的横向位置以它靠右的边缘为准；纵向位置以它靠卷头的边缘为准。宽、长是实际疵点尺寸，避让外扩单独填写。
7. 记录自动保留在当前浏览器。删除可以撤销；刷新后自动恢复母卷、跑布位置与未保存记录。
8. 点「保存到母卷」把本次新增疵点一起入档。网络异常时保留本地记录，重复保存不会重复生成疵点。新疵点会用于裁切避让；原有排料方案需要重新核对、生成。

「全卷」或左侧全卷导航可回看标记；「回到验布线」恢复当前位置。浏览不会改变累计长度。窄窗口默认收起右侧面板，通过画布右上角面板按钮展开。

保存仅追加本次疵点，保留母卷的库存数量、已用长度和已有疵点。已入档的疵点在此页面只读。「已到卷尾」只表示位置到达末端，不自动判定质量合格，也不表示机器已经完成验布。

## 验证

- Java：`InspectionTests` 覆盖原子保存、断线重试、位置精度、边界校验和历史记录兼容。
- Node：`src/test/js/inspection.test.mjs` 覆盖拖框、整卷坐标和恒速位置换算。
- 浏览器：`src/test/browser/inspection.cjs`，要求使用 `BASE_URL` 指定非 8080 的隔离服务。创建独立测试母卷，不触碰工作台业务库存。
