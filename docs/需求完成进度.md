# 需求完成进度

左侧需求区同时回答两个问题：哪些需求已经满足，以及最近一次报工使哪些数量发生了变化。

- 顶部显示“已满足 3 / 5 项”和“合格 13 / 20 件”。每个分段对应一项需求：绿色勾选表示全部满足，蓝色填充表示部分完成，空段表示尚未完成。点击分段展开并定位对应需求。超过 12 项时使用整体进度条，逐项进度仍在列表中显示。
- 每条需求显示“合格完成 6 / 10 件 · 还差 4 件”和进度条。最近一次报工涉及的需求显示“最近报工 +2 件”；展开顶部“查看变化”可以集中查看本次影响的需求并定位。
- 进度概览在需求列表收起时保留，列表滚动时固定在顶部。键盘焦点进入进度区后，不触发画布移动或旋转。

## 数量口径

完成量沿用服务器任务汇总中的合格报工数量。生成方案、手动调整、异常件和未切件均不提前增加完成量；预览数量另列为“本方案 N 件 · 待报工”。

最近变化读取当前任务的持久报工记录，按确认或撤回时间选择最近一次。撤回后进度条回退，并显示“恢复待切 N 件”。重新打开任务可看到最近记录，新建任务不携带原任务变化。旧记录缺少逐项明细时明确显示未登记，不从总件数推测需求归属。它表示最近一次操作，不累计多次操作，也不因刷新而重新扣减。

```sh
node --test src/test/js/*.test.mjs
node src/test/browser/plan-adjustment.cjs
node src/test/browser/task-drafts.cjs
```

本次只调整展示与读取已存在的汇总/回执，不改变报工扣减或库存事务。浏览器用例不替代生产数据库写入与现场裁切验收。
