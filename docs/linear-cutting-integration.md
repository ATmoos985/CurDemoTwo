# 一维分切接入

入口为 `/linear.html`，顶部「一维分切」在独立浏览器 tab 打开。与二维裁切同用一个 Spring Boot 服务，不依赖本机的另一个项目目录或 8081 服务。

## 物理口径

母卷宽、左右固定切边、组合宽范围独立传入。可切区 = 母卷宽 − 左切边 − 右切边，组合上限不得超过可切区。固定组合宽用相同的上下限表示，仍保留原母卷总宽。

分切图沿母卷全宽等比例显示「左固定边、成品、可切区余边、右固定边」。重复用卷数不重复横向宽度。整卷得率按面积统计；可切区利用率按重复用卷数累计宽度统计。需求按卷长、表面处理及幅宽分别核对，未产出的需求仍显示缺口。

沿用长阳模型的整数 mm / 整数 m / 整数卷；不支持通过取整输入小数尺寸。页面指标及导出均为预计方案，不能当作实切完成。

## 任务与并发

`POST /api/linear/tasks` 创建任务，`GET /api/linear/tasks/{id}` 查询状态与结果。重切 / 撤销携带方案编号和基础版本，过期版本拒绝。每个任务独立持有算法实例、方案上下文、待处理记录和撤销栈。不同任务不会读取服务器的全局“最近结果”。同一任务计算中禁止修改或导出。

重切只能选择同一卷长、表面处理分组。共享同一原始切割批次的显示组合需一同选择，避免误删未选组合；页面会联选共享批次。重切后的产出、余边等按真实新结果更新。

计算队列为 2 个工作线程、8 个排队位置，容量满时明确拒绝。最多暂存 100 个任务，非运行任务闲置 8 小时过期。方案是服务内存数据，重启后失效。当前 tab 使用 sessionStorage 保存输入草稿和任务编号；修改后的草稿刷新时不会被旧结果覆盖。关闭 tab 后不承诺保留草稿，请及时导出。
